# marks

Fallback marks, generated by `plate` and dropped here as `<mark>.svg` (full)
and `<mark>.min.svg` (coarse). When a project's `mark` names a file here that
nullsilver.com has not committed to `src/lib/marks/` yet, the site fetches and
inlines these instead — so a freshly registered project is never markless. Once
the mark is committed to the site, the site's copy wins and the file here is
just provenance.

Bars must be `fill="currentColor"` — the site inlines the SVG so the theme can
color it; a hardcoded fill would ignore dark mode.
